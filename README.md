# Diabetes Prediction Project
A machine learning project that predicts whether a person has diabetes
based on medical details like glucose, BMI, insulin, age, and blood pressure.
## Features
- Cleans and preprocesses the dataset
- Trains a model to classify diabetic / non-diabetic
- Shows accuracy and performance results
- Predicts diabetes for new patient input
## Dataset
Pima Indians Diabetes Dataset (768 records, 8 features)
## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn
## How to Run
1. Clone the repo:
   git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
2. Go to the folder:
   cd YOUR-REPO
3. Install the libraries:
   pip install -r requirements.txt
4. Run the project:
   python main.py
